El presente proyecto de análisis de datos trata acerca de la elaboración de un reporte formulado en Excel, el cual busca ser de apoyo para analizar el histórico de llamadas de un Centro de contacto Telefónico. 

Dicho proyecto fue elaborado como "Proyecto integrador" del curso de Análisis de datos impartido por la academía de cursos online Código Facilito.

Es importante mencionar que, el hecho de que haya sido realizada como "Medio de graduación de curso", no es un proyecto ficticio, ya que forma parte importante de mi experiencia real como analista de datos en TKM Customer Solutions.

Se parte de un set de datos real, sin embargo, este ha sido modificado con la finalidad de cuidar los principios de seguridad de información. El compartamiento de las llamadas, como la fecha, la hora, así como datos no sensibles no han sido alterados para mantener lo más real posile el reporte.

Se adjunta un archivo ".pdf" dónde se documenta el proyecto, así como una versión recortada del reporte (ya que no es posible subir la versión completa por el peso que dicho archivo tiene).

Las herramientas utilizadas para este proyecto fueron Microsoft Excel y python.

1.- Se parte de un archivo xlsx (formato Excel), conformado de 45 columnas y 218mil filas aproximadamente; con un peso alrededor 31mb , el cuál fue limpiado para disminuir su peso eliminando data innecesaria para el proyecto.

2.- La limpieza fue realizada en un entorno de Jupyter Notebook utilizando lenguaje Python y la librería pandas; el cuál puede encontrar dentro de la carpeta "Notebook". Una vez realizada la limpieza del archivo original, se obtuvo un archivo con solo 10 columnas y las mismas filas, sin embargo, el peso se redujo considerablemente en poco más del 50%; a aproximadamente 14mb. Dicho archivo lo puede encontrar en la carpeta "Data y reporte" con el nombre de data_reporte.xlsx.

3.- Una vez con el archivo limpio se procedió a realizar el reporte formulado, el cuál lleva por nombre "Análisis de llamadas" y que puede encontrar dentro de la carpeta "Data y reporte".

NOTA: El reporte es "pesado"; aproximadamente 30mb, por lo que en caso de querer interactuar con este, es necesario descargarlo. Puede hallar visualizaciones dem las slides del reporte dentro de la carpeta "Vistas del reporte".
